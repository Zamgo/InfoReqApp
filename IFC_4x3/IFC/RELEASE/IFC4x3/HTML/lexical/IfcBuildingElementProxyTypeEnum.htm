6.1.2.3 IfcBuildingElementProxyTypeEnum

6.1.2.3.1 Semantic definition

This enumeration defines the available generic types for IfcBuildingElementProxy or IfcBuildingElementProxyType.

HISTORY New enumeration IFC2x3
IFC4.3.0.0-CHANGE Enumerators PROVISIONFORVOID and PROVISIONFORSPACE deprecated. Use an IfcVirtualElement with PROVISIONFORVOID and CLEARANCE at IfcVirtualElementTypeEnum instead.
IFC4-CHANGE Enumerators PROVISIONFORVOID and PROVISIONFORSPACE added.

DEPRECATION The enumerator COMPLEX, ELEMENT, PARTIAL shall no longer be used.

6.1.2.3.2 Type values

6.1.2.3.3 Formal representation 

TYPE IfcBuildingElementProxyTypeEnum = ENUMERATION OF
	(COMPLEX
	,ELEMENT
	,PARTIAL
	,PROVISIONFORSPACE
	,PROVISIONFORVOID
	,USERDEFINED
	,NOTDEFINED);
END_TYPE;
